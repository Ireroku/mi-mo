# 権限を使う理由

Chrome Web Store の「プライバシーへの取り組み」タブと、Firefox Add-ons の審査向けのメモへ写す文。権限は `wxt.config.ts` の `manifest.permissions` と、content script の `matches` から決まる。権限を足したら、ここにも1項目足す。

## 単一用途

三重大学 Moodle 4（lms-m41.mie-u.ac.jp）に、時間割表示・上部メニューに時計を表示・資料の一括保存 などの機能を追加します。学生の利便性が向上することを目的としています。

## storage

拡張機能の設定を保存するために使用しています。保存したデータはブラウザ外に送信されません。
設定には、機能のオン・オフ、時間割情報、ユーザ設定の「一言」機能、上部メニュー要素の表示・非表示などが含まれます。

## downloads

利用者が授業コースページで「資料を保存」ボタンを押下した際に資料（PDFや画像）をダウンロードするために使用します。オリジナルのファイル名でダウンロードするために必要です。

## ホストへのアクセス（https://lms-m41.mie-u.ac.jp/*）

三重大学 Moodle 4 のページへスクリプトやUI要素を挿入するために使用します。
「評点の表示」と「資料の保存」機能では、ログイン中ユーザとしてデータやファイルを読むために使用します。

## リモートコード

なし。全コードが同梱されています。

## 自動検査の警告

Firefox の審査向けのメモにだけ写す。

自動検査の「Unsafe assignment to innerHTML」の警告は、Svelte 5 の runtime（`svelte/src/internal/client/dom/reconciler.js`）から出ています。コンパイル時に作られた固定の HTML の型紙を `<template>` へ入れる処理で、ページの内容や利用者の入力は渡りません。拡張機能自身のコードは innerHTML を使っていません。Svelte の版は `package.json` にあります。
