# 権限を使う理由

Chrome Web Store の「プライバシーへの取り組み」タブと、Firefox Add-ons の審査向けのメモへ写す文。権限は `wxt.config.ts` の `manifest.permissions` と、content script の `matches` から決まる。権限を足したら、ここにも1項目足す。

## 単一用途

三重大学 Moodle 4（lms-m41.mie-u.ac.jp）の画面に、時間割・時計・資料の一括保存などの機能を足し、使いやすくします。

## storage

拡張機能の設定（機能ごとの入り切り、時間割、時限表、カウントダウンの対象など）をブラウザの中に保存するために使います。保存した値は利用者のブラウザの外へ送りません。

## downloads

利用者がコースページで「資料を保存」を押した時にだけ、セクションの資料（PDF など）をまとめてダウンロードするために使います。保存する名前を元のファイル名にするため、ダウンロードの API に名前を添えて渡します。

## ホストへのアクセス（https://lms-m41.mie-u.ac.jp/*）

三重大学 Moodle 4 のページへ部品を足し、表示を変えるために使います。評点の表示とページ資料の保存では、同じサイトの評定ページと資料を、ログイン中の利用者として読みます。このサイト以外のページでは動きません。

## リモートコード

使いません。動くコードはすべて拡張機能の中に入っています。
