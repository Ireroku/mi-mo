# timetable ics モジュール

## 概要

時間割をカレンダーアプリで読める `.ics` の文字列へ書き出す。通常の授業は週ごとの繰り返しルールで表し、休講日は除外日として抜き、振替日だけを個別の予定として足す。

## 関連

- 使う: [`./schedule.md`](./schedule.md) — 実日程と、各コマの最終回の日
- 使う: [`../utils/periods.md`](../utils/periods.md) — 各時限の開始・終了時刻
- 資料: [`../../features/home/timetable.md`](../../features/home/timetable.md) — 書き出しが必要な理由

## 対象ファイル

| パス | 役割 |
|---|---|
| `src/features/timetable/ics.ts` | `.ics` の文字列の組み立て |

## インターフェース

```ts
// src/features/timetable/ics.ts
export const ICS_FILENAME = "timetable.ics";

export function buildIcs(
  config: TimetableConfig,
  periods: PeriodSlot[],
): string;
```

文字列を返すところまでを担当する。ファイルとして保存させる処理は [`../settings/timetableFields.md`](../settings/timetableFields.md) が持つ。

## 処理の流れ

1. `buildSchedule` で実日程を組み立てる
2. `VCALENDAR` の開始行を書く（`VERSION:2.0`、`PRODID` に mi-mo の名前、`CALSCALE:GREGORIAN`）
3. `grid` のうち `null` でないコマそれぞれについて、繰り返しの `VEVENT` を1つ書く
4. 振替日に行う授業それぞれについて、繰り返さない `VEVENT` を1つ書く
5. `VCALENDAR` の終了行を書く

### 繰り返しの VEVENT

| プロパティ | 値 |
|---|---|
| `UID` | コマを一意に表す文字列。曜日と時限から作り、末尾に `@mi-mo` を付ける |
| `DTSTAMP` | 書き出した時刻 |
| `DTSTART` | そのコマの初回の日と、時限の開始時刻 |
| `DTEND` | 同じ日と、時限の終了時刻 |
| `RRULE` | `FREQ=WEEKLY;BYDAY=<曜日>;UNTIL=<そのコマの最終回>` |
| `EXDATE` | 休講で飛んだ日の開始時刻を並べる |
| `SUMMARY` | `slot.title` |
| `URL` | `slot.url`（無ければ書かない） |

`BYDAY` は `MO`・`TU`・`WE`・`TH`・`FR` を使う。

### 振替の VEVENT

振替日に行う授業は、繰り返しルールに乗らないため個別に書く。`RRULE` と `EXDATE` を持たず、`UID` はコマの `UID` に日付を足して別物にする。`SUMMARY` は同じ。

### 日時の書き方

すべて UTC で書き、末尾に `Z` を付ける（例: `20260410T040000Z`）。日本標準時から9時間引いた値になる。

授業の日時は常に日本標準時として解釈し、`Date.UTC` で組み立てる。実行環境のタイムゾーンを使わない。海外から書き出しても同じ内容になる。

### 値のエスケープ

`SUMMARY` などのテキストは、次の順で置き換える。

| 元 | 置き換え後 |
|---|---|
| `\` | `\\` |
| `;` | `\;` |
| `,` | `\,` |
| 改行 | `\n` |

### 行の折り返し

1行が 75 オクテットを超える場合、その位置で改行し、次の行の先頭に半角スペースを1つ置く。日本語は1文字あたり3オクテットになるため、文字の途中で切らないよう、オクテット数を数えながら文字単位で折る。

## 決めごと

- **ライブラリを使わず自前で組み立てる。** 使うのは `VEVENT`・`RRULE`・`EXDATE` の3つだけで、時刻も日本標準時に固定できる。依存を足しても書く量がほとんど減らない
- **`VTIMEZONE` を書かず、UTC で書く。** タイムゾーン定義を持ち込まずに済み、読む側のアプリを選ばない。日本標準時には夏時間が無いため、固定の時差で正しく変換できる
- **繰り返しの終わりを `COUNT` ではなく `UNTIL` で書く。** `COUNT` は `EXDATE` で除外した回を数に含めるかどうかの解釈がアプリによって割れる。`UNTIL` に最終回の日を書けば、どのアプリでも同じ日程になる
- **休講は `EXDATE`、振替は個別の予定にする。** 休講はその回が消えるだけで済む。振替は「別の曜日の授業を、その曜日でない日に行う」もので、週ごとの繰り返しでは表せない
- **`UID` を曜日と時限から作る。** 同じ時間割を書き出し直した時に、カレンダー側が同じ予定として上書きできる
- **ファイル名は `timetable.ics` で固定する。** 学期や年度を名前に入れると、設定を変えた後の書き出しと食い違う
- **書き出すのは現在の設定1つ分だけ。** 過去の学期を残す仕組みは作らない
