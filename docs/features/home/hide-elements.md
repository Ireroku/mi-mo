# 不要な要素の非表示化

## 何ができるか

ホームに表示される要素のうち、使わないものを隠す。対象は3つ。

- お知らせ
- コースカテゴリ
- コース検索

## なぜ必要か

いずれも日常的に使わないまま場所を占めている。特にコースカテゴリとコース検索は、自分が履修しているコースへ行くだけなら一度も触らない。

隠せば、その場所を時間割や挨拶といった実際に見るものへ回せる。

## 対象

ホーム。

## 設定項目

それぞれについて隠すかどうか。
