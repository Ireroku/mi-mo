# 気さくな挨拶

## 何ができるか

ホームに挨拶を表示する。「こんにちは、<ユーザー名>さん」という呼びかけと、その時々で変わる一言を含める。

呼びかけの言葉は時間帯に合わせて変わる。

| 時刻 | 言葉 |
|---|---|
| 5時から11時まで | おはようございます |
| 11時から18時まで | こんにちは |
| 18時から翌5時まで | こんばんは |

時間帯によらない「ごきげんよう」へ固定する、言葉を置かず名前だけにする、のどちらも選べる。

一言には、mi-mo に入っている既定の一言と、自分で足した一言が混ざって出る。既定の一言は学生あるある・豆知識・名言などで、版を重ねるごとに増やす。既定の一言を切って、自分の一言だけにもできる。

自分の一言の内容は自由に決める。「今日も一日、無理せずいきましょう。」のような素直なものから、「あんた、宿題やったの！？」「睡眠時間を減らすと効率が落ちるそうですよ。寝ましょう。」のようなものまで。候補が2件以上ある場合、続けて同じ一言は出ない。

自分の一言は、テキストファイルで出し入れできる。1行が1件。ファイルを読み込むと、今の候補と入れ替わる。数十件をまとめて用意する時や、他の人と候補を交換する時に使う。

## なぜ必要か

Moodle 4.5 はログイン直後に「こんにちは、<ユーザー名>！」というメッセージを出す。これには**ログインが成功したという事実がはっきり分かる**という価値がある。副次的に、どのアカウントで入っているかも分かる。

ただし画面を遷移するとこのメッセージは消える。同じものを常に表示し続けたい。

どうせ常時出すなら、毎回同じ文面では飽きる。そこへ一言を添える。賑やかしとして。

## 対象

ホーム。ログインしていない間は出さない。

## 設定項目

| 設定 | 内容 |
|---|---|
| 表示 | 挨拶を出すかどうか |
| 名前の前の言葉 | 時間帯に合わせる、「ごきげんよう」、なし、のいずれか |
| mi-mo の一言を使う | 既定の一言を候補に入れるかどうか |
| 自分の一言 | 自分で足す一言の一覧。表示のたびに、既定の一言と合わせた中から1つが選ばれる。ファイルへの書き出しと、ファイルからの読み込みができる |
