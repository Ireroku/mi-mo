# 時間割カレンダー

## 何ができるか

自分の時間割をホームに表示する。ここで設定した内容は、マイコースの並び順にも使う。

### 時間割の設定

曜日と時限ごとに授業を登録する。登録内容は自由に編集できる。

### コマからのリンク

各コマをクリックした時の遷移先を設定する。そのコースのコースページを指定すれば、時間割から直接移動できる。

### `.ics` でのエクスポート

時間割をカレンダーアプリで読み込める形式へ書き出す。

### 変則的な予定の一括設定

- **休みの設定** — 休講日や大学の休業日を指定する
- **代替日の入れ替え** — 「この日は月曜日の授業を行う」といった振替を設定する

### 授業の週の表示

その授業が何回目かを表示する。代替日による振替があっても、回数を正しく数える。

### 色

白・黒・水色・ピンク・緑から選べる。

### ダークモード

ダークモードに対応する。

## なぜ必要か

時間割は毎日確認するもので、Moodle を開いた時点で目に入る場所にあるのが自然になる。

大学の時間割は休講や振替で変則的に動く。そのため「今日は何限があるか」「この授業は何回目か」が把握しにくい。授業の回数は出席の管理にも関わるため、振替があっても正しく数えられる必要がある。

各コマからコースページへ直接飛べれば、マイコース一覧を経由する動作が消える。

色を選べるようにするのは、毎日見るものなので。

## 対象

ホーム。

## 設定項目

| 設定 | 内容 |
|---|---|
| 時間割 | 曜日・時限ごとの授業名 |
| リンク先 | 各コマをクリックした時の遷移先URL |
| 休み | 授業を行わない日 |
| 代替日 | 別の曜日の授業を行う日と、その曜日 |
| 色 | 白 / 黒 / 水色 / ピンク / 緑 |
