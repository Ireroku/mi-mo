# 時間割カレンダー

## 何ができるか

自分の時間割をホームに表示する。ここで設定した内容は、マイコースの並び順にも使う。

### 時間割の設定

曜日と時限ごとに授業を登録する。登録内容は自由に編集できる。

### コマからのリンク

各コマをクリックした時の遷移先を設定する。そのコースのコースページを指定すれば、時間割から直接移動できる。

### `.ics` でのエクスポート

時間割をカレンダーアプリで読み込める形式へ書き出す。

### ファイルでの出し入れ

時間割をファイルへ書き出し、別のブラウザや別の人の mi-mo で読み込める。ファイルに入るのは、授業科目とリンク先、休み、代替日、学期の開始日、授業の回数、時限表（時限の名前・並び・時刻）。表示の入り切りと色は入らず、読み込んだ側の設定がそのまま残る。時限表の入っていない以前のファイルを読んだ場合は、今の時限表が残る。

読み込む前に、今の内容が上書きされることを確かめる。「読み込む」を押すと、今の内容がファイルの内容と入れ替わる。

### 時限表の編集

時限ごとに名前と開始・終了の時刻を決める。名前は自由に付けられ、何も書かなければ「一限」「二限」のように出る。時限はドラッグで並べ替えられ、時間割はその順に並ぶ。名前や並びを変えても、登録した授業は同じ時限に残る。

### 変則的な予定の一括設定

- **休みの設定** — 休講日や大学の休業日を指定する
- **代替日の入れ替え** — 「この日は月曜日の授業を行う」といった振替を設定する

### 授業の週の表示

その授業が何回目かを表示する。代替日による振替があっても、回数を正しく数える。

### 色

Moodle・白・黒・水色・ピンク・緑から選べる。「Moodle」は Moodle のカードと同じ色で、何も選んでいない時の色になる。

### ダークモード

ダークモードに対応する。

## なぜ必要か

時間割は毎日確認するもので、Moodle を開いた時点で目に入る場所にあるのが自然になる。

大学の時間割は休講や振替で変則的に動く。そのため「今日は何限があるか」「この授業は何回目か」が把握しにくい。授業の回数は出席の管理にも関わるため、振替があっても正しく数えられる必要がある。

各コマからコースページへ直接飛べれば、マイコース一覧を経由する動作が消える。

同じ学科の学生は、ほぼ同じ時間割を持つ。1人が入力したものをファイルで配れば、残りの人は打ち込まずに済む。

色を選べるようにするのは、毎日見るものなので。

## 対象

ホーム。ログインしていない間は出さない。

## 設定項目

| 設定 | 内容 |
|---|---|
| 時間割 | 曜日・時限ごとの授業名 |
| リンク先 | 各コマをクリックした時の遷移先URL |
| 休み | 授業を行わない日 |
| 代替日 | 別の曜日の授業を行う日と、その曜日 |
| 時限表 | 各時限の名前、並び、開始と終了の時刻。時計の時限表示と共有する |
| 学期の開始日 | 授業の回数を数え始める日 |
| 授業の回数 | 1つの授業が何回で終わるか |
| 色 | Moodle / 白 / 黒 / 水色 / ピンク / 緑。既定は Moodle |
