# 多言語対応

未実装。着手する前の方針だけを置く。

## 何ができるか

mi-mo が足す部品、設定画面、ストアに出る説明文を、ブラウザの表示言語で出す。

## なぜ必要か

三重大学には留学生が多く、日本語の画面だけでは使いにくい人がいる。

## 対象

mi-mo が出すすべての文言。Moodle 自身の文言は Moodle の言語設定に従うため、対象に含めない。

## 言語

| 言語 | ロケール |
|---|---|
| 英語（既定） | `en` |
| 日本語 | `ja` |
| 中国語（簡体字） | `zh_CN` |
| 中国語（繁体字） | `zh_TW` |
| 韓国語 | `ko` |
| ドイツ語 | `de` |

既定の言語は英語にする。上の表に無い言語のブラウザでも、日本語より読める人が多いため。翻訳は LLM による機械翻訳で作る。

## 方針

- **言語はブラウザの表示言語に従う。** WXT 公式の `@wxt-dev/i18n` を使い、ブラウザの `i18n` の仕組みに任せる。この仕組みは拡張機能の中から言語を切り替えられない。Moodle の言語に合わせる、設定で選ぶ、という形は、要望が出てから自前の読み込みで足す
- **既定の一言は言語ごとのファイルに分ける。** 一言の多くは日本の大学生活に根ざしており、訳すと意味が通らない。`greetings.ja.txt`、`greetings.en.txt` のように言語ごとに中身を作り、ファイルが無い言語では英語を使う。初めは日本語と英語だけを置く
- **manifest の説明文も言語ファイルへ移す。** 移した後は、説明文の正本が `package.json` から言語ファイルへ変わる
