# 右側のクイックドロワー

## 何ができるか

Moodle の右側に表示されるドロワーに対して、2つの操作を行う。

### ドロワーの削除

ドロワー自体を隠す。

### コースのピン留め

任意のコースをドロワーへ固定して並べる。そこから直接コースページへ移動できる。

## なぜ必要か

右側ドロワーは画面幅を占有するが、表示される内容は必ずしも必要でない。不要なら隠せた方が本文の表示領域が広がる。

一方で、よく使うコースへ素早く移動したい需要はある。ドロワーを「自分が選んだコースへの入口」として使えれば、マイコース一覧を経由せずに移動できる。隠すか、使えるものに作り変えるか、どちらかを選べる状態にする。

## 対象

右側ドロワーが表示されるページ。

## 設定項目

- ドロワーを隠すかどうか
- ピン留めするコース
