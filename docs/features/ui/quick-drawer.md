# 右側のクイックドロワー

## 何ができるか

Moodle の右側に表示されるドロワーに対して、2つの操作を行う。狭い画面では、上部メニューに入りきらない時計とカウントダウンの置き場所にもなる。

### ドロワーの削除

ドロワー自体を隠す。

### コースのピン留め

任意のコースをドロワーへ固定して並べる。そこから直接コースページへ移動できる。

### 時計

上部メニューで時計の一部かカウントダウンが消えた時、ドロワーの先頭に「時計」ブロックを出す。ピン留めのブロックより上に置く。時計は時刻・日付・時限のうち設定で表示するものをすべて出し、カウントダウンはメニューから消えた件だけを出す。メニューに収まっている間はブロックを出さない。消え方と表示の形は [上部メニュー](./menu.md) の「狭い画面」にある。

## なぜ必要か

ドロワーに表示される内容は必ずしも必要でない。不要なら視界から外す。

一方でそこは、画面上の余っている場所でもある。どうせ空いているなら、よく使うコースへの入口として使い道を与えられる。隠すか、使えるものに作り変えるか、どちらかを選べる状態にする。

狭い画面で上部メニューから消えた時計とカウントダウンも、同じ空いた場所で読めるようにする。メニューの幅に合わせて消すだけでは、狭い画面の利用者は時刻と残り時間を知る手段を失う。

## 対象

右側ドロワーが表示されるページ。

## 設定項目

- ドロワーを隠すかどうか
- ピン留めするコース

時計のブロックに専用の設定は無い。ドロワーを隠している間は出さない。
