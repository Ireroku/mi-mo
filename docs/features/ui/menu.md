# 上部メニュー要素の削除・追加

## 何ができるか

Moodle のナビゲーションメニューを編集する。4つの機能を含む。

### 項目の削除

メニューに並ぶ項目のうち、使わないものを隠す。トップレベルの項目（ドロップダウン全体）と、その中のサブ項目のどちらも指定できる。

設定画面で隠す項目を書く時、Moodle で最後に開いたページのメニュー項目名を候補として出す。候補から選ぶか、名前をそのまま書く。Moodle をまだ開いていない間は候補が出ない。

### 項目の追加

任意のリンクをメニューへ追加する。別タブで開くかどうか、既存項目の前後どちらに置くかを指定できる。

### 時計

メニューの右端、通知の左に現在時刻を表示する。左に時限の名前（「三限」）を縦書きで置き、その右に時刻（「14:05」）と日付と曜日（「11/17 火」）を二段に積む。日付と曜日をどちらも表示しない場合は時刻の1段になる。

時限の名前は縦に1列2文字、2列までで出す。5文字以上の名前は、先頭3文字に「…」を付けて縮める。全文はマウスを重ねると読める。

秒・日付・年・曜日・時限のそれぞれについて表示するかを選べる。12時間表記（「午後2:05」）へも切り替えられる。初めは日付・曜日・時限を表示する。

時限は時限表に基づいて判定する。初めは三重大学の標準時限割（一限 08:50-10:20 から六限 18:00-19:30）が入っている。時限の名前は時限表で付けたものを出す。授業時間の外では、時限を表示しない。

### カウントダウン

指定した時刻までの残り時間を、時計の左に表示する。複数個を同時に並べられる。数える先は2種類ある。

| 種類 | 数える先 | ラベル |
|---|---|---|
| 日時を指定 | 設定した日時 | 設定したもの |
| 今の時限の残り時間 | 授業中は今の時限の終了、休み時間と最初の時限の前は次の時限の開始 | 「三限 終了まで」「四限 まで」を自動で出す |

「今の時限の残り時間」は、その日の最後の時限が終わると「授業終了」を薄く出し、翌日の時限は数えない。

時間割に授業が入っていて時間割を有効にしている間は、授業のある時限だけを数える。授業の無い時限は、休み時間と同じく飛ばす。時間割の設定「カウントダウンを時間割に合わせる」で切り替えられる（[時間割](../home/timetable.md)）。

残り時間に応じて粒度が自動で切り替わる。切り替わる残り時間は設定で変えられる。既定は次の通り。

| 残り | 表示 |
|---|---|
| 15分以下 | 秒まで |
| 24時間以下 | 分まで |
| 7日以下 | 日と時間 |
| 7日超 | 日のみ |

目標時刻を過ぎた場合は「終了しました」と表示する。非表示にはしない。

1 件を二段で、左揃えで表示する。上段がラベル、下段が残り時間。ラベルは空白の位置で改行し、さらに 4 文字ごとに折り返して 2 行まで出す。収まらない分は「…」で省く。ラベルの文字は、時計の日付と同じ大きさと色にする。

### 狭い画面

画面が狭い時は、メニューの項目へ場所を譲る。カウントダウンは、メニューの空きに入りきらなくなった件から消える。後ろの件から先に消え、空きが戻ればまた出る。スマートフォンほどの幅では Moodle のメニューが三本線のボタンにまとまって空きができるため、カウントダウンがまた出ることがある。

時計の各段は画面の幅で、次の順に消す。

1. 時限
2. 日付
3. 時刻

右側のドロワーを出している間は、メニューから消えた時計とカウントダウンをドロワーの先頭の「時計」ブロックへ移す。時計は一部でも消えるとすべての段をブロックに出し、カウントダウンは消えた件だけを出す。何も消えていない間はブロックを出さない。ドロワーを隠す設定の間と、ドロワーの無いページでは、消えたものはどこにも出ない（[右側のクイックドロワー](./quick-drawer.md)）。

### ロゴの非表示

Moodle のロゴを隠す。

## なぜ必要か

三重大学の Moodle には大学独自のリンクが多数並ぶが、その大半は日常的に使わない。

消せば場所が空く。そこへ時刻や締め切りまでの残り時間という、実際に何度も確認するものを置く。この機能では「消す」と「足す」が同じ動機の表裏になっている。

## 対象

Moodle の全ページ。ナビゲーションメニューは共通して表示されるため。

4つの機能すべてについて、PC表示のトップバーとモバイル表示のドロワーの両方を対象とする。

## 設定項目

| 設定 | 内容 |
|---|---|
| 隠す項目 | 項目名またはURLの一部を文字列で列挙する |
| 追加する項目 | 表示名・URL・別タブで開くか・挿入位置 |
| 時計の表示項目 | 12時間表記にするか。年・日付・曜日・秒・時限のそれぞれについて表示するか |
| 時限割 | 各時限の開始時刻と終了時刻 |
| カウントダウンの対象 | 種類（日時を指定・今の時限の残り時間）。日時を指定する場合はラベルと日時 |
| 残り時間の刻み | 秒まで出す残り（1〜60分前から）、分まで出す残り（1〜72時間前から）、日と時間を出す残り（1〜30日前から）。すべてのカウントダウンに共通 |
| ロゴ | 隠すかどうか |

「日時を指定」でラベルが空で日時も入っていないカウントダウンは、設定画面で「戻る」を押した時に消える。
