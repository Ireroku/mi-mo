# 上部メニュー要素の削除・追加

## 何ができるか

Moodle のナビゲーションメニューを編集する。4つの機能を含む。

### 項目の削除

メニューに並ぶ項目のうち、使わないものを隠す。トップレベルの項目（ドロップダウン全体）と、その中のサブ項目のどちらも指定できる。

### 項目の追加

任意のリンクをメニューへ追加する。別タブで開くかどうか、既存項目の前後どちらに置くかを指定できる。

### 時計

メニュー上に現在時刻を表示する。上段に時刻と時限（「14:05 3限」）、下段に日付と曜日（「11月17日(火)」）を置く。

秒・日付・年・曜日・時限のそれぞれについて表示するかを選べる。12時間表記（「午後2:05」）へも切り替えられる。初めは日付・曜日・時限を表示する。

時限は三重大学の標準時限割（1限 09:00-10:30 から 6限 18:00-19:30）に基づいて判定する。授業時間の外では、時限を表示しない。

### カウントダウン

指定した時刻までの残り時間を表示する。複数個を同時に並べられる。

残り時間に応じて粒度が自動で切り替わる。

| 残り | 表示 |
|---|---|
| 15分以下 | 秒まで |
| 24時間以下 | 分まで |
| 7日以下 | 日と時間 |
| 7日超 | 日のみ |

目標時刻を過ぎた場合は「終了しました」と表示する。非表示にはしない。

1 件を二段で表示する。上段がラベル、下段が残り時間。長いラベルは 2 行まで折り返し、収まらない分を「…」で省く。

画面が狭い時は、メニューの項目へ場所を譲る。まずラベルを消して残り時間だけにし、さらに狭ければ 2 件目以降を消す。

### ロゴの非表示

Moodle のロゴを隠す。

## なぜ必要か

三重大学の Moodle には大学独自のリンクが多数並ぶが、その大半は日常的に使わない。

消せば場所が空く。そこへ時刻や締め切りまでの残り時間という、実際に何度も確認するものを置く。この機能では「消す」と「足す」が同じ動機の表裏になっている。

## 対象

Moodle の全ページ。ナビゲーションメニューは共通して表示されるため。

4つの機能すべてについて、PC表示のトップバーとモバイル表示のドロワーの両方を対象とする。

## 設定項目

| 設定 | 内容 |
|---|---|
| 隠す項目 | 項目名またはURLの一部を文字列で列挙する |
| 追加する項目 | 表示名・URL・別タブで開くか・挿入位置 |
| 時計の表示項目 | 秒・12時間表記・日付・年・曜日・時限のそれぞれについて表示するか |
| 時限割 | 各時限の開始時刻と終了時刻 |
| カウントダウンの対象 | 識別子・ラベル・目標時刻 |
| ロゴ | 隠すかどうか |

カウントダウンの粒度切替の閾値（15分 / 24時間 / 7日）は固定値として持ち、設定では変えられない。
