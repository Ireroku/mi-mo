# シームレスに統合された拡張機能設定ボタン

## 何ができるか

mi-mo の設定画面を開くボタンを、Moodle の UI に馴染む見た目で配置する。ブラウザのツールバーにある拡張機能アイコンを経由せず、Moodle のページ上から直接設定を開ける。

## なぜ必要か

拡張機能の設定はふつうブラウザのツールバーから開くが、その動線は Moodle を使っている最中の流れから外れる。設定項目の多くは「今見ているページの見え方」を変えるものなので、そのページ上から開けた方が早い。

加えて、ツールバーのアイコンはブラウザの設定によって折りたたまれていることがあり、そもそも存在に気付きにくい。

## 対象

Moodle の全ページ。

## 設定項目

なし。
