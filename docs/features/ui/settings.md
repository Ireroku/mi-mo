# 拡張機能の設定画面

## 何ができるか

mi-mo のすべての設定を GUI で行う画面を用意する。ブラウザのツールバーから開くポップアップには、同じ画面をそのまま表示する。

画面はレスポンシブに作り、ポップアップの狭い幅でも広い画面でも1枚で兼ねる。

## なぜ必要か

隠すメニュー項目・時計の表示内容・カウントダウンの対象といった設定をソースコード内の定数として持つと、変更するたびに拡張機能をビルドし直す必要があり、実質的に開発者しか設定を変えられない。

設定画面を1枚だけ作り、それをポップアップへ流し込む形にすれば、実装も画面も分散しない。Moodle のページ上へ設定ボタンを埋め込むかどうかは、この画面ができた後に決めればよく、機能の本体ではない。

同じ方式を Control Panel for Twitter が採っている。

## 対象

ブラウザのツールバーから開くポップアップ。

## 設定項目

この画面自体の設定はない。
