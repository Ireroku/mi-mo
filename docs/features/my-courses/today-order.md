# カレンダーと同期して「今日の授業順」で表示

## 何ができるか

マイコースの一覧を、今日の授業の順番で並べ替える。並び順には時間割カレンダーで設定した内容を使う。

## なぜ必要か

標準の並び順は、今日どの授業があるかと無関係に決まる。そのため、今日受ける授業のコースへ行きたいだけでも、一覧から目で探すことになる。

授業順に並んでいれば上から順に使える。探す動作そのものが消える。

## 対象

マイコース。

## 設定項目

並べ替えを有効にするかどうか。
