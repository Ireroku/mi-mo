# 即座に絞り込む検索

## 何ができるか

マイコースの検索で、文字を入力した瞬間に結果を絞り込む。サーバーへの問い合わせを待たない。

## なぜ必要か

Moodle の標準実装も打鍵のたびに絞り込む作りにはなっている。ただし、そのたびにサーバーへ問い合わせ、コース一覧をフィルター行ごと丸ごと描き直す。結果が出るまで最低でも1.5秒かかる。

1.5秒待たされる検索は、体感として「絞り込まれない」のと変わらない。目的のコースが現れるまで手を止めて待つことになり、それなら一覧を目で追った方が速い。

マイコースの一覧は、ページを開いた時点で全件が画面上に揃っている。サーバーへ問い合わせる必要がない。手元で絞り込めば待ち時間そのものが消える。

マイコース。
