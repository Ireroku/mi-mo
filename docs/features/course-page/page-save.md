# ページ資料の本文を保存

## 何ができるか

コースセクションに置かれた「ページ」（Moodle の中に本文を直接書く形の資料）を、本文と画像ごと手元へ保存する。セクションの「資料を保存」を押すと、PDF などのファイルと一緒に保存される。

ページ資料の画面でも、「完了マークする」の帯の右端の「資料を保存」で、そのページだけを `<ページ名>.zip` として保存できる。

課題の画面でも、同じ「資料を保存」で `<課題名>.zip` を保存できる。中の Markdown は、開始・期限・提出できるファイルの種類を先頭の YAML Frontmatter に、課題の説明を本文に書く。開始・説明・ファイルの種類は、課題に無ければ書かない。提出の内容は変わらない。

```markdown
---
title: "第6回課題②"
url: "https://lms-m41.mie-u.ac.jp/mod/assign/view.php?id=161249"
due: 2026-11-24T00:00
file_types:
  - ".pdf"
  - ".wav"
---

本日の内容をトレースする形で……
```

セクションの中のページは、まとめて1つの ZIP（`<セクション名>.zip`）になる。ZIP の中では、1つのページが1つのフォルダになる。

どの画面でも、保存する中身が Markdown 1つだけ（画像も添付も無いページや課題が1件）なら、ZIP にせず `<ページ名>.md`（課題なら `<課題名>.md`）として保存する。

```text
講義資料.zip
  第１回講義資料/
    第１回講義資料.md    本文。画像は下のファイルを相対パスで指す。本文へ直に埋め込まれた画像も、ファイルに分ける
    001.PNG
    002.PNG
    ...
  第２回講義資料/
    ...
```

## なぜ必要か

資料の置き方は教員によって違う。PDF を置く教員もいれば、スライドを画像にしてページへ並べる教員も、本文をページへ直接書く教員もいる。

「資料を保存」が集めるのはファイルだけで、ページは対象に入らない。「書き出す」はコースページに見えている範囲を書き出すため、ページはリンクと名前だけになる。どちらを使っても、ページの中身は手元に残らない。

置き方の違いを利用者が意識せず、同じボタンで全部を保存できるようにする。

## 対象

コースページと、セクションの個別ページ（`course/section.php`）、ページ資料の画面（`mod/page/view.php`）、課題の画面（`mod/assign/view.php`）。保存の対象は、セクションの中の「ページ」（`modtype_page`）か、開いているページか課題。
