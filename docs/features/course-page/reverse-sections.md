# コースセクションの順序を逆転して表示

## 何ができるか

コースセクションの並び順を逆にする。最新の回が一番上に来る。

## なぜ必要か

授業は回を追うごとにセクションが下へ追加されるため、最新の回が一番下に置かれる。しかし実際に一番使うのは最新の回。

そのため授業が進むほど、目的の場所へ着くまでのスクロール量が増える。終盤には毎回長くスクロールすることになる。

## 対象

コースページ。

## 設定項目

逆転するかどうか。既定は逆転しない。
