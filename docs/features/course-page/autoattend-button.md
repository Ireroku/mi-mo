# autoattend による出席リンクをボタン化

## 何ができるか

autoattend の出席リンクを、押しやすいボタンとして表示する。配置はコースの最上部かフローティングUIのどちらかを選べる。

## なぜ必要か

出席を登録するには、まず「出席を取る」リンクを押し、出席コードの入力画面へ移動し、そこでコードを入力する。コードの入力は避けられないが、その手前の1回は省ける。

授業のたびに、しかも授業の開始直後や途中という急いでいる場面で発生する操作なので、1回分でも削る価値がある。

## 対象

autoattend が設置されたコースページ。

## 設定項目

ボタンの配置（コース最上部 / フローティング）。
