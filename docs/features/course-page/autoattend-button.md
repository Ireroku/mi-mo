# autoattend による出席リンクをボタン化

## 何ができるか

autoattend の出席リンクを、押しやすいボタンとして表示する。配置はコースの最上部かフローティングUIのどちらかを選べる。

## なぜ必要か

出席を登録するには、コース内容の中から出席リンクを探して押す。授業の開始直後や途中という急いでいる場面で、セクションを目で追ってリンクを探すのは負担になる。

常に決まった位置にボタンがあれば、探す動作そのものが消える。

加えて、**そのコースが autoattend で出欠を取るかどうかが、ページを開いた時点で分かる。** 出席を取る授業かどうかは押す前に知りたい情報なので、ボタンの有無がそのまま答えになる。

## 対象

autoattend が設置されたコースページ。

## 設定項目

ボタンの配置（コース最上部 / フローティング）。
