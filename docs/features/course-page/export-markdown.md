# コースセクションの要素を Markdown / テキストでダウンロード

## 何ができるか

コースセクションに並ぶ要素（課題、資料へのリンク、説明文など）を Markdown またはプレーンテキストとして書き出す。セクション単位で一括して行える。

## なぜ必要か

コースページの内容は Moodle の中にしか無い。手元のノートやタスク管理へ取り込みたい場合、1つずつ手で写すことになる。

書き出せれば、自分の環境で検索も整理もできる。

## 対象

コースページ。

## 設定項目

出力形式（Markdown / プレーンテキスト）。
